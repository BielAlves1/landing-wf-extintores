# WF Extintores — Landing page
HTML, CSS e JavaScript puros. Abra `index.html` no navegador ou envie o conteúdo da raiz do projeto para a hospedagem via FTP.

## Personalização
- Textos, serviços, links e contatos: `dist/index.html`.
- Cores, fontes e responsividade: `dist/styles.css`.
- Swiper: banners descobertos automaticamente em `assets/banners` pela sequência `01.jpg`, `02.jpg`, etc.; autoplay de 3000 ms, fade, anterior/próximo, pausa, contador automático e zoom Ken Burns. A sequência termina no primeiro número ausente.
- AOS: `once: false` e `mirror: true`, com animações repetidas de entrada e saída.
- Bibliotecas via CDN: Swiper 11.2.10, AOS 2.3.4 e Lucide 0.468.0; fontes via Google Fonts. Há navegação de reserva e conteúdo visível quando os scripts externos falham.
- Movimento reduzido: desabilita animações e autoplay inicialmente. O visitante pode ativar os banners pelo botão de reprodução.
